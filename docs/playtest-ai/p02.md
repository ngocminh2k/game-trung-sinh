## Fullerton — 5 Questions
1. **What are the goals?** Clear enough: cultivate, survive, get stronger. But nothing quantifies "stronger" — stage never moved and stats can't be spent, so I couldn't tell what winning a day even means.
2. **What interesting decisions do you face?** Thin. Fight-vs-skip and buy-vs-save exist. Combat's attack-vs-technique Qi tradeoff is the one genuinely interesting choice. Gambling and stat-spending are both broken/shallow.
3. **Do the rules make sense?** Core loop does (qi cost → damage → retaliation). But no visible stat model and a disabled allocation UI make progression illegible.
4. **Is the challenge balanced?** On hard, early combat is a net-negative grind — 21 HP for 32 gold. Either I'm missing a power curve, or it's tuned to punish.
5. **Does it grab you emotionally?** No. It's a text log with a HUD. For a genre vet, the fantasy of *advancing a realm* is exactly what's missing.

## Bugs & Friction
- **[BUG] Stat points unspendable.** "Thêm điểm THẦN/TÂM/MẠCH/VẬN" button (`#` `[34]`) is disabled; click times out after 20s. Progression dead-ends. Highest-impact bug found.
- **[BUG] NPC dialog modal blocks clicks.** Talking to Thợ rèn Đức `[26]` → `proto-modal-backdrop … .floor intercepts pointer events`; interaction unusable until Escape.
- **[CONFUSION] UI is Vietnamese despite selecting English.** Telemetry run record confirms `locale:"vi"`. Every label, dialog, and item name is vi. Locale selection had no visible effect.
- **[CONFUSION] No stat breakdown on the character sheet.** THẦN/TÂM/MẠCH/VẬN values never displayed numerically; can't min-max blind.
- **[CONFUSION] Free-text command input is silently dead.** Typing "tìm Thiềm Thừ Độc Sương" into Nhập mệnh lệnh produced no response, no intel, no encounter — the input field exists and accepts text but the world never acknowledges it. Reads as a broken affordance.
- **[BUG] Named boss Thiềm Thừ Độc Sương unreachable on demand.** It's not an NPC or button anywhere I could reach; presumably gated behind random movement encounters, so a player who wants that specific fight has no way to trigger it. Blocked my intended endgame action.
- **[NIT] train gives no visible feedback** — HUD unchanged (stage 0), unclear if it did anything.
- **[NIT] No damage numbers in combat.** Had to read HP/Qi deltas off the HUD to infer combat math.
- **[NIT] Gambling is a flat tax** — 20 gold for +1 herb, no odds shown, no payout variety.
- **[NIT] Free/instant travel** removes any journey tension from the map.
