## Vấn đề gốc (root cause)

### 1. `.game-shell` chỉ là grid 1-CỘT (mobile-first)

**File:** `src/index.css:87`
```css
.game-shell{display:grid;width:min(1510px,calc(100vw - 32px));height:100dvh;
margin:0 auto;padding:12px 0;grid-template-rows:auto auto minmax(0,1fr);gap:10px;overflow:hidden}
```

→ Chỉ có 3 rows: `topbar | stage-notices | world-content`. Không có cột cho left-rail hay right-hud.

**Kết quả:** Mọi thứ stack theo chiều dọc, bị main overflow:hidden che mất.

### 2. `.hud-panel` có width 1408px (full-width thay vì ~320px)

Hud-panel đang là grid 1-cột full-width của shell thay vì 1 cột bên phải của desktop grid 3-cột.

**File:** `src/index.css:91`
```css
.map-panel,.story-panel{min-height:0;height:100%;padding:14px;overflow:hidden}
.hud-panel{min-height:0;height:100%;grid-template-rows:auto auto minmax(0,1fr);gap:9px;overflow:hidden}
```

→ `.hud-panel` chỉ set `min-height: 0; height: 100%` — nhưng vì shell chỉ có 1 cột, nó phải xuống hàng tiếp theo, bị đẩy ra ngoài viewport.

### 3. `.world-content` chỉ 235px (do bị giới hạn bởi stage-notices + world-content đang share cùng 1 row)

Vì layout là 1-cột, world-content chỉ chiếm 1 phần của viewport sau topbar + stage-notices.

### 4. `.drawer-panel` (system-dock) ở trong game-shell, không phải position:fixed

Hệ thống dock ở góc (16, 315) thay vì dock right-side, bị tràn ra ngoài.
